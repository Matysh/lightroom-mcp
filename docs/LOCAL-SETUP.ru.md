# Локальная сборка для Codex и Claude на Windows

Этот форк использует Lua-плагин Automaat внутри Lightroom Classic и локальный MCP-сервер.
Скрипт `scripts/start-local.mjs` запускает собранный сервер из этого checkout и по умолчанию
включает все группы инструментов (`core`, `develop`, `masks`). Явно заданное значение
`LIGHTROOM_MCP_TOOLSETS` имеет приоритет; `LIGHTROOM_MCP_READ_ONLY` продолжает работать.

## Сборка и установка

Требуется Node.js 20+ и Lightroom Classic. Из корня репозитория:

```powershell
npm.cmd --prefix server ci
node server/dist/index.js install-plugin
```

Плагин копируется в `%APPDATA%\Adobe\Lightroom\Modules\LightroomMCP.lrplugin`.
В Lightroom откройте File → Plug-in Manager → Add, выберите эту папку.
Сервер плагина запускается автоматически; Lightroom должен оставаться открытым.

После изменения Lua-файлов обновите установленную копию и перезапустите Lightroom.
`install-plugin` сохраняет уже установленную папку: для обновления сначала сделайте её
резервную копию вне репозитория, затем скопируйте поверх содержимое
`plugin/LightroomMCP.lrplugin`. После изменения TypeScript достаточно `npm.cmd --prefix server run build`
и перезапуска MCP-клиентов.

## Codex и Claude Code

Из корня репозитория, после резервного копирования конфигураций:

```powershell
$repoPath = (Resolve-Path .).Path
$nodePath = (Get-Command node.exe).Source
$launcherPath = Join-Path $repoPath 'scripts\start-local.mjs'
codex mcp add lightroom -- $nodePath $launcherPath
claude mcp add --scope user --transport stdio lightroom -- $nodePath $launcherPath
claude mcp add --scope local --transport stdio lightroom -- $nodePath $launcherPath
```

Пользовательская запись Claude Code действует в других проектах, локальная — в этом checkout.
Репозиторный `.mcp.json` также запускает локальный launcher; он требует запуска Claude Code
из корня checkout и предварительной сборки сервера.

## Claude Desktop

В `%APPDATA%\Claude\claude_desktop_config.json` добавьте запись `lightroom` в существующий
объект `mcpServers`, сохранив остальные серверы. В `args` нужен абсолютный путь к launcher:

```json
{
  "mcpServers": {
    "lightroom": {
      "command": "C:\\Program Files\\nodejs\\node.exe",
      "args": ["C:\\path\\to\\lightroom-mcp\\scripts\\start-local.mjs"]
    }
  }
}
```

После изменения конфигураций перезапустите Codex и Claude Desktop, а для Claude Code
откройте новую сессию. Проверка ниже сама запускает MCP-процессы с записанными конфигурациями;
она не перезапускает приложения и не доказывает, что уже открытый чат обновил список инструментов.

## Проверка подключения

```powershell
claude mcp get lightroom
node server/scripts/verify-local.mjs
```

Вторая команда читает конфигурации Codex, Claude Code и Claude Desktop, одновременно
открывает три MCP-соединения, проверяет инструменты проявки, читает выделенный снимок
и его настройки. Изменений снимков нет. Требуется установленный Codex CLI.

Для явного теста записи на одном известном снимке:

```powershell
node server/scripts/smoke-photo.mjs PHOTO_ID
```

Команда создаёт одну виртуальную копию, сохраняет snapshot, получает превью, увеличивает
экспозицию на 0,5 EV и контраст на 10, проверяет значения и изменение превью, затем
восстанавливает snapshot и проверяет настройки исходного снимка. Оставляет копию и snapshot
для просмотра. При ошибке после создания snapshot также пытается восстановить копию;
результат восстановления записывается в отчёт. Выбирайте снимок, у которого эти значения
ещё не достигли максимума.

JSON-отчёты и JPEG «до / после / восстановлено» сохраняются в `.cache/verification/`.
Эта папка исключена из Git: отчёты могут содержать пути и метаданные личных фотографий.
Превью из кеша Lightroom может запаздывать после правки; тест ждёт обновления и читает его дважды.

## Скилл: проявка RAW по сгенерированному референсу

Общий скилл [lightroom-reference-edit](../skills/lightroom-reference-edit/SKILL.md)
читает выделенный RAW и его настройки, сохраняет native snapshot до правок, получает превью,
генерирует референс света и цвета и делает обычно 2–4 прохода настройки Lightroom.
После каждого прохода проверяет сохранённые значения и свежий JPEG; в конце сохраняет
финальный snapshot и показывает «до / референс / результат».
Для рабочих превью, входа генерации и сравнений использует JPEG с длинной стороной
768 px, quality 80. Финальный рендер проверяет один раз при 2048 px, quality 90;
крупные превью и кропы запрашивает отдельно при необходимости проверить детали.
Встроены обход ошибки `error loading thumb`, обработка диалога AI Updates при экспорте
и последовательное выполнение вызовов проявки и масок.

Для личной установки скопируйте **всю папку** `skills/lightroom-reference-edit`:

| Клиент | Каталог назначения | Явный вызов |
| --- | --- | --- |
| Codex | `%USERPROFILE%\.codex\skills\lightroom-reference-edit` (либо `$CODEX_HOME/skills/lightroom-reference-edit`) | `$lightroom-reference-edit` |
| Claude Code | `%USERPROFILE%\.claude\skills\lightroom-reference-edit` | `/lightroom-reference-edit` |

Если папка назначения уже существует, сначала сохраните её собственные изменения.
После установки откройте новый чат/сессию. При загрузке этого checkout как Claude Code plugin
скилл также доступен как `/lightroom:lightroom-reference-edit`; отдельная личная копия тогда
не обязательна. Не подключайте второй MCP-сервер, если локальный `lightroom` уже настроен.

Для **Claude Desktop** упакуйте папку скилла целиком в ZIP и загрузите через
Customize → Skills → + → Create skill → Upload a skill. В архиве должен быть путь
`lightroom-reference-edit/SKILL.md` вместе с `references/` и `agents/`.
Установка в `.claude/skills` относится к Claude Code; она сама по себе не устанавливает
скилл в Desktop. [Официальная инструкция импорта](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

Пример запроса:

> Используй lightroom-reference-edit: возьми выделенный RAW, сгенерируй реалистичный
> референс с мягким светом и естественным цветом, затем приблизь проявку к нему.
> Сохрани snapshot до правок и проверь результат после каждого прохода.

Lightroom MCP не генерирует изображения. В Codex скилл использует доступный инструмент
генерации; в Claude нужен подключённый image-to-image генератор либо готовый референс
от пользователя. При отсутствии генератора скилл сообщает об этом, не подменяя генерацию
текстовым описанием. Скилл не добавляет инструменты сам: MCP-сервер и нужные группы
`core`, `develop`, `masks` должны быть доступны в текущем клиенте.

## Исправление `error loading thumb`, 16 ноября 2026

На Windows вызов `requestJpegThumbnail` возвращал ошибку сразу, даже при наличии
Smart Previews и успешном JPEG-экспорте. Переход в Library восстановил получение
превью; после возврата в Develop запрос продолжил работать.

Плагин теперь автоматически пробует этот способ при конкретной ошибке
`error loading thumb`: на короткое время открывает Library и повторяет запрос,
затем восстанавливает модуль и выделение. Использует общий блокировщик операций
Develop, не меняет настройки снимка и не запускает экспорт с диалогом AI Updates.
Мгновенные ошибки повторяются до трёх секунд; ожидание асинхронного рендера
ограничено общим таймаутом запроса превью.
Другие ошибки, например недоступный файл, возвращаются сразу.

Для применения Lua-исправления обновите установленную копию `HandlerPreview.lua`
и выполните Reload Plug-in в Plug-in Manager; перезапуск MCP-клиентов для самого
Lua-обработчика не требуется. Перед обновлением сохраните копию установленного плагина.

После перезагрузки плагина выделенный `DSC00523.ARW` вернул JPEG 640×960 через MCP
за 51 мс; ранее проблемный `DSC00408.ARW` — за 99 мс. Настройки проявки и выделение
до/после совпали. Ошибка в этих запросах не возникла, поэтому живой вызов ветки
восстановления ими не подтверждён. Сам переход в Library при ошибке, возврат модуля
и выделения, ограничение повторов и конфликт с другой операцией Develop проверены
Lua-тестами с имитацией ответа SDK.

## Проверено 15 ноября 2026

- Windows, Node.js 22.23.2, Lightroom Classic 15.6, исходная версия сервера 0.27.0.
- Три одновременных соединения видят 72 инструмента, включая `set_develop_settings`.
- Чтение EXIF и Develop, JPEG-превью 1920×1280 для Sony ARW.
- Правка экспозиции 0 → 0,5 EV и контраста 0 → 10 на виртуальной копии подтверждена чтением.
- Превью изменилось; snapshot восстановил все возвращаемые Develop-настройки копии.
- Возвращаемые Develop-настройки оригинала до и после проверки совпали.

Маски, Denoise и пакетная обработка этим запуском не проверялись.
